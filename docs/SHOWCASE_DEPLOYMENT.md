# DataReady NVIDIA Showcase — Safe Cloud Run Deployment

The project has two **separate** FastAPI entrypoints:

| Entrypoint | Purpose | Model calls |
| --- | --- | --- |
| `app.web:app` | Existing Gemini workflow, protected NVIDIA live demo, and local showcase | Gemini / authenticated NVIDIA requests |
| `app.public_showcase:app` | Public, judge-facing **synthetic strategy replay** | **No Gemini or NVIDIA endpoints** |

**Never replace the existing `dataready-autopilot` Cloud Run service when publishing the showcase.** Use a new service instead.

The public showcase replays the two action types observed during a real NVIDIA Nemotron inference, but newly computes its own deterministic isolated-trial outcomes. It does **not** make fresh model calls or require API secrets.

## Local verification (macOS)

From the repository root on the correct feature branch:

```bash
./.venv/bin/python -m pytest -q
```

Stop any local Uvicorn process with Ctrl+C and start the **public-only** entrypoint:

```bash
./.venv/bin/python -m uvicorn app.public_showcase:app --host 127.0.0.1 --port 8080
```

Open http://127.0.0.1:8080/ and verify:

- The root redirects to `/showcase`.
- The `/showcase/evidence` endpoint returns the measured recommendation.
- `POST /demo/repair` and `POST /demo/nebius-candidates` return HTTP 404.
- `/health` returns a healthy response.

## Verify the Google Cloud project before deployment

```bash
gcloud config get-value project
gcloud run services list --region us-west1 --format='table(metadata.name,status.url)'
```

**Verify** that you are deploying to the intended billing project; Cloud Run deployment creates billable cloud resources. Do not assume the Google Cloud CLI project matches a previously deployed service.

## Deploy a new, standalone public service

Run this from the repository root:

```bash
gcloud run deploy dataready-nvidia-showcase \
  --source . \
  --region us-west1 \
  --allow-unauthenticated \
  --min-instances 0 \
  --max-instances 2 \
  --memory 1Gi \
  --cpu 1 \
  --set-build-env-vars 'GOOGLE_ENTRYPOINT=uvicorn app.public_showcase:app --host 0.0.0.0 --port 8080'
```

This uses the Python buildpack and deploys a **new** service. It does not update the existing `dataready-autopilot` service or attach `GOOGLE_API_KEY`, `NEBIUS_API_KEY`, or `DATAREADY_DEMO_ACCESS_TOKEN` environment variables.

Do not pass API keys on the command line or deploy local `.env` files. The repository contains a `.gcloudignore` file that excludes local secrets and development files.

## Verify the deployed service

Use the URL printed by `gcloud run deploy`. In a browser:

1. Open the service root and verify it redirects to `/showcase`.
2. Click **Explore the candidates** and confirm the two choices: 80 vs 90 audit score with the second strategy recommended.
3. Open `/showcase/evidence` and confirm `live_inference_performed=false` and `source_preserved=true`.
4. Confirm the live model endpoints are **not** registered on this public service (404).

The new service is public by design, and **re-evaluates the synthetic dataset per request**, consuming Cloud Run compute. `--min-instances 0` and `--max-instances 2` limit standing resources and scaling but do not guarantee zero cost or provide a fixed spending cap. Set a Cloud Billing budget and alerts if desired.

## Competition truthfulness

- The original NVIDIA-generated **action types** were confirmed in the local live inference test.
- The public page reconstructs that action pair; it does not store or claim verbatim model responses.
- Recommendation, audit scores, and preservation checks are regenerated by DataReady on the public service.
- The 90-point recommendation is **not** proof that all quality problems were resolved. A missing-value issue remains.
- No production writes or release approvals occur.

For a live, credentialed NVIDIA demonstration, use the existing `app.web:app` entrypoint in a **private, local environment**. Never expose that endpoint without authentication and usage controls.
